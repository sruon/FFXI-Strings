# FFXI-Strings (archived)

This repository is archived. [FFXI-Resources](https://github.com/sruon/FFXI-Resources) now dumps FFXI's strings for every client version.

- Browse them: <https://res.sruon.dev> (pick a version, then Strings)
- Download them: the `strings` files on each [FFXI-Resources release](https://github.com/sruon/FFXI-Resources/releases)

The old dumps are in this repository's history.
